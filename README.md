# Electronic Dice

<img width="360" height="495" alt="image" src="https://github.com/user-attachments/assets/b8418431-04d0-431a-803a-0c0af5659c34" />

The circuit simulates a dice roll.  
While the button is held, the numbers loop continuously from **1 to 6**.  
When the button is released, the loop stops and displays a **random number** between 1 and 6.
